# Video Scripter 短视频脚本创作工具

**一份需求，为每个发布平台各写一份拿来就能拍的脚本。**

Video Scripter 是一个短视频脚本工作台。把视频描述一次，勾选要发布的平台，每个平台都会得到一份单独的脚本：按该平台的受众、节奏和发布规则来写，还能根据分镜直接生成画面图片和视频片段。

它运行在你自己的电脑上，接入你已经在用的模型服务商，所有脚本、图片和视频都保存在你自己的文件夹里。

[English](README.md)

## 为什么用 Video Scripter

- **一份需求，五个平台。** 抖音脚本和 YouTube Shorts 脚本本来就是两种写法。每个平台各写一份，而不是一稿到处贴。
- **拿来就能拍。** 每个场景都有时间码，并写好旁白、屏幕文字、画面、镜头和声音。
- **拿来就能发。** 每份脚本都附带标题、封面文字、描述文案、话题标签和置顶评论。
- **自带分镜画面。** 任意场景都能生成 9:16 的图片或视频片段，有 27 种画面风格可选。
- **模型随你选。** 内置十个服务商预设，从 OpenAI、Anthropic 到通义千问、豆包和本地 Ollama，也支持任何兼容 OpenAI 或 Anthropic 接口的服务。每份脚本都可以换模型。
- **内容归你所有。** 不用注册账号，不上云，不用安装依赖。所有内容保存在本地磁盘，并可打包成一个整齐的 `.zip`。

## 快速开始

需要 Node.js 20 或以上版本。

```bash
npm install
```

```bash
ADMIN_EMAIL=you@example.com ADMIN_PASSWORD='设置一个足够长的密码' npm start
```

打开 http://localhost:3789 ，用上面的邮箱和密码登录。`ADMIN_EMAIL` 和 `ADMIN_PASSWORD` 只在首次启动时用于创建管理员，之后可以省略；其他人在登录页自行注册。首次启动是演示模式，只返回占位文字，方便你在没有模型的情况下先熟悉流程。点击 **模型设置** 连接真实模型。

## 使用流程

### 1. 填写需求

只有主题是必填的，其余各项用来让结果更准。

| 字段 | 作用 |
| --- | --- |
| 主题 | 这条视频讲什么 |
| 发布平台 | 勾选几个平台，就写几份脚本 |
| 脚本结构、时长 | 叙事框架和视频长度 |
| 画面风格 | 选一种，或选两种混合；用于分镜描述和所有生成的图片、视频 |
| 核心信息、目标受众、语气风格 | 希望观众记住的那句话、写给谁看、听起来是什么感觉 |
| 品牌或创作者、行动号召 | 谁在说话，希望观众接下来做什么 |
| 参考资料 | 事实、引语或一篇文章。模型被要求只使用这里或需求中出现过的数据和引语 |
| 旁白用于语音合成 | 把数字和符号写成读法，让语音合成读得正确 |
| 写作模型 | 用哪个网关和模型来写这份脚本 |

### 2. 查看脚本

每个平台一个标签页，脚本边写边显示。一份脚本包括：

- **三个开场钩子备选**，从中挑一个开头
- **带时间码的分镜列表**，每个场景都有旁白、屏幕文字、画面、镜头和声音
- **只看旁白** 视图，方便录音或粘贴到语音合成工具
- **发布素材**：标题、封面文字、描述文案、话题标签和置顶评论

**重新生成** 会重写这份脚本。**复制 Markdown** 和 **复制旁白** 可把内容复制到剪贴板。

### 3. 生成画面

当前使用的网关设置了图像或视频模型后，每个场景下会出现 **生成图片** 和 **生成视频** 按钮，把该场景的画面和镜头描述变成 9:16 的图片或视频片段。在需求里勾选 **同时为每个场景生成图片**，脚本写完后会自动为所有场景出图。

### 4. 导出

**下载 .zip** 会把脚本、旁白以及所有已生成的图片和视频打包成一个压缩包，按场景编号命名（见[你的内容](#你的内容)）。

## 脚本结构

六种结构决定故事怎么展开，以及时长在各个阶段之间如何分配。

| 结构 | 展开方式 | 适合 |
| --- | --- | --- |
| 黄金留存（硬核认知） | 钩子、悬念锚点、三层价值、结构化收束、无预警收尾 | 商业、科技、认知类内容 |
| 痛点-放大-解决 | 先戳痛点，再放大代价，最后给解法 | 服务、课程、工具类 |
| 故事反转 | 从结果或冲突切入，讲一个有转折的小故事 | 个人 IP、品牌故事、案例 |
| 清单盘点 | "3 个……"式清单，最有价值的一条放最后 | 技巧、避坑、盘点 |
| 教程步骤 | 先展示结果，再分步骤教 | 实操、软件、技能教学 |
| 产品种草 | 场景痛点、产品亮相、卖点证明、行动 | 带货、新品、探店 |

## 画面风格

**画面风格** 提供 27 种风格，分为五组。

| 分组 | 风格 |
| --- | --- |
| 实拍 | 电影感、纪实、手机实拍、棚拍产品、明亮生活方式、现代职场、微距特写 |
| 插画 | 扁平矢量、等距视角、手绘草图、水彩、国风水墨、动漫、美漫波普、拼贴 |
| 三维与定格 | 风格化三维、黏土定格、质感三维 |
| 图形与数据 | 动态信息图、极简几何、科技界面、屏幕演示 |
| 年代与氛围 | 复古胶片、霓虹夜色、暗调质感、像素风、超现实梦境 |

可以选一种，或选两种混合。先选的为主；再选第三种时，会替换掉最早选的那一种。所选风格有两个作用：

1. 告诉写作模型这种风格能呈现什么，让每个场景的画面和镜头描述与之相配。
2. 写进这份脚本所有图片和视频的提示词。

写脚本时没有选风格的，生成图片和视频时会使用当时选中的风格。

## 图片和视频

**每个场景的图片数**（1 到 3，默认 1）决定每次点击 **生成图片** 或自动出图时，为一个场景生成几张图。每张图都是对图像模型的一次单独请求。

生成两张或三张时，旁边的下拉框决定这几张图之间的关系：

| 模式 | 2 张 | 3 张 | 用途 |
| --- | --- | --- | --- |
| 备选方案 | 同一镜头两张 | 同一镜头三张 | 多生成几张，挑最好的 |
| 动作节拍 | 开始、结束 | 开始、中段、结束 | 做轮播，或作为图生视频的首尾帧 |
| 多景别 | 全景、特写 | 全景、中景、特写 | 在一个场景内剪切 |
| 主镜头 + 插入镜头 | 主镜头、细节插入 | 主镜头、细节插入、环境空镜 | 用于穿插剪辑 |
| 风格对比 | 风格 A、风格 B | 风格 A、风格 B、混合 | 在所选的两种画面风格之间做选择 |

每张图都有自己的提示词：场景的画面描述，加上这张图对应的拍法。多景别和插入镜头会替换场景原有的镜头描述，动作节拍则保留。每张图下方会标注它的角色，压缩包里的文件名也会带上（如 `scene-01_00m00s-00m04s_1-wide.png`）。

> **提示：** 各张图是独立生成的。提示词会要求同一组图保持主体、场景和色调一致，但图像模型仍可能有差异。

视频片段的时长取 4、8、12 秒中能覆盖该场景的最短一档；超过 12 秒的场景按 12 秒生成。

## 连接模型

生成内容通过 **网关** 完成。一个网关包含服务商、接口地址、API 密钥和模型。

| 设置 | 模型设置中的字段 | 环境变量 |
| --- | --- | --- |
| 服务商 | 服务商 | `LLM_PROVIDER` |
| 接口地址 | BASE_URL_API | `BASE_URL_API`（或 `LLM_BASE_URL`） |
| API 密钥 | API_KEY | `API_KEY`（或 `LLM_API_KEY`） |
| 模型 | 默认模型 | `LLM_MODEL` |

### 支持的服务商

OpenAI、Anthropic (Claude)、DeepSeek、通义千问、豆包、Moonshot Kimi、智谱 GLM、Google Gemini、OpenRouter、Ollama（本地），以及自定义的 OpenAI 兼容接口、Anthropic 兼容接口和离线演示。

预设的接口地址和模型名称只是起点，请按你的账号实际情况修改。

### 保存多个网关

在 **模型设置** 里可以保存任意多个网关，每个服务商或账号一个。可以编辑、删除，并在要用的那个上勾选 **用这个网关写脚本**。

- 保存的网关写入 `data/gateway.json`，优先级高于环境变量。环境变量只在没有保存任何网关时提供初始网关。
- **测试连接** 可以在保存之前检查网关设置是否可用。

### 模型

**列出可用模型** 会向服务商查询当前密钥可以使用哪些模型。勾选想用的模型并选定默认模型后，所有已保存网关中勾选的模型都会出现在需求里的 **写作模型** 选择器中，管理员不用打开设置就能切换网关和模型，选择对所有人生效。

如果服务商没有模型列表接口，直接输入模型名称即可。

### 图像和视频模型

每个网关都有 **图片和视频** 一栏，可以为图片和视频分别设置 BASE_URL_API、模型、尺寸和可选的 API_KEY。

- 接口地址或密钥留空时，使用网关本身的设置。
- 模型留空即关闭该类生成。
- 尺寸只在填写后才会发送。
- **列出可用图像模型** 和 **列出可用视频模型** 会向对应地址查询模型。服务商会返回它的全部模型，名称看起来像图像或视频模型的会排在前面。

## 你的内容

所有内容都保存在服务端，并按用户隔离。

| | 本地运行（`npm start`） | 线上部署（设置了 `DATABASE_URL`） |
| --- | --- | --- |
| 脚本、用户、会话、用量、活动日志、网关 | `data/<名称>.json` | Postgres 表 `vs_docs` |
| 生成的图片和视频 | `data/media/` | Postgres 表 `vs_blobs` |

图片和视频是私有的，只有所有者和管理员可以打开。

从历史记录重新打开脚本时，它的图片和视频会一并显示。重新生成图片或视频不会删除旧文件，界面显示最新的一份。如果服务商返回的是链接而不是文件，文件也会被下载并保存。

备份或迁移到另一台电脑时，复制整个 `data/` 目录即可。

### 下载的压缩包

**下载 .zip** 为每份脚本生成一个压缩包，文件名为 `<日期>_<平台>_<标题>.zip`，例如 `2026-11-10_douyin_AI-落地的三个坑.zip`。标题保留各种语言的文字，标点和空格换成连字符，最长 40 个字符。压缩包内是一个同名文件夹：

```
script.md                              完整脚本，使用界面语言
script.html                            同样内容的网页版，带图片和视频，可离线打开
script.json                            需求、计划、脚本，以及媒体文件列表
voiceover.txt                          只有旁白，每个场景一段
images/scene-01_00m00s-00m04s.png      每个场景最新的图片
videos/scene-01_00m00s-00m04s.mp4      每个场景最新的视频片段
```

一个场景有多张图片时，文件名会加上序号，有角色的还会带上角色：`…_1.png`，或 `…_1-start.png`、`…_2-end.png`。

## 账号、用量与活动日志

- **注册和登录**：邮箱加至少 8 位的密码，会话有效期 30 天。
- **两种角色**：*成员* 可以写脚本、生成图片和视频，并查看自己的历史、用量和活动；*管理员* 还可以管理模型网关（网关和模型由管理员统一设置并对所有人生效；成员看不到接口地址和密钥，只能看到正在使用的网关和模型），以及查看和管理所有用户。
- **第一个管理员** 由环境变量 `ADMIN_EMAIL` 和 `ADMIN_PASSWORD` 创建。注册不会获得管理员权限；管理员在 **用户管理页**（`/admin.html`，顶部栏和账号面板中都有入口）管理其他所有人。
- **用量**：每一次模型调用都会记录：谁调用的、属于哪份脚本、用了哪个网关和模型、输入和输出 Token、生成的图片数、视频秒数、耗时以及是否失败。**账号 → 用量** 按时间段显示总量，并按脚本、按模型、逐次调用列出；管理员可以切换到 **所有用户** 查看每个用户的用量。服务商不返回 Token 数时按文本估算，并标记为 ≈。
- **活动日志**：**账号 → 活动日志** 记录注册、登录和登录失败、脚本生成、图片和视频生成、打包下载，以及网关和用户的变更。密码和 API 密钥不会写入日志。
- 设置 `ALLOW_SIGNUP=false` 可关闭注册。

- **个人资料**：任何人都可以在 **账号 → 个人资料** 中修改自己的显示名称和密码；修改密码后其他设备会退出登录。
- **显示密码**：所有密码和 API 密钥输入框都有一个眼睛按钮，可以显示已输入的内容。
- **用户管理页**（仅管理员）：列出所有账号及其角色、状态、最近登录、脚本数和用量，支持搜索和筛选。管理员可以创建用户（密码可手动输入或自动生成）、修改姓名、邮箱、角色和状态、重置密码、强制在所有设备退出登录、查看单个用户的会话、累计用量和最近活动，以及删除用户（可选择删除其脚本和素材，或转到管理员名下）。管理员不能降级、停用或删除自己的账号。

暂未包含：邮箱验证和通过邮件自助找回密码；忘记密码时由管理员重置。

## 部署到 Vercel

仓库可以直接部署：`vercel.json` 选择 "Other" 框架预设，把 `public/` 作为静态文件，并把 `/api/*` 和 `/media/*` 交给一个 Node.js 函数（`api/index.mjs`）。

1. **添加 Postgres 数据库**：在 Vercel 项目的 **Storage** 中创建 Postgres（Neon）数据库，它会自动加入 `DATABASE_URL`。数据表在第一次请求时自动创建。
2. **添加两个环境变量**：`ADMIN_EMAIL` 和 `ADMIN_PASSWORD`（密码请标记为 Sensitive）。
3. **重新部署**，打开网站，用管理员账号登录，在 **模型设置** 中连接模型。

没有 `DATABASE_URL` 时网站仍可运行，但使用的是临时存储，函数重启后账号、脚本和设置都会丢失；此时管理员在账号面板中会看到提示。

## 隐私与安全

- **需要登录。** 除注册和登录外，所有接口都需要会话，并拒绝跨站请求。
- **不保存密码原文。** 只保存加盐的 scrypt 哈希；连续 5 次输错密码会锁定账号 15 分钟。
- **密钥留在服务端。** 每个密钥随所属网关保存，管理员只能看到打码后的预览，成员完全看不到。
- **密钥不会发给别的服务。** 更改网关的服务商或接口地址会清除已保存的密钥。
- **不进入版本库。** `data/` 已加入 .gitignore。

你的需求和参考资料只会发送给你选择的模型服务商。

## 界面

- **语言。** 顶栏的 **中文 / English** 按钮在简体中文和英文之间切换界面。在你选择之前，界面跟随浏览器语言。服务端和模型服务商返回的信息仍为英文。
- **主题。** 顶栏的太阳 / 月亮按钮在浅色和深色之间切换。在你选择之前，页面跟随系统设置。
- **四步填写需求。** 你的视频、脚本结构、画面与图片、补充信息。后两步默认折叠，只显示一行摘要。**生成** 栏始终在手边。
- **桌面端。** 左边是需求，右边是脚本。历史记录和模型设置从顶栏打开。
- **手机端。** 一次只显示一个视图，底部导航栏有创作需求、脚本、历史记录、设置四项。开始生成后会自动切到脚本视图，设置和历史记录以全屏面板打开。控件高度不低于 44px，输入框使用 16px 文字，在 iOS 上点击输入框时页面不会被放大。
- **历史记录。** 带缩略图的列表，可以搜索。
- **写作过程中。** 进度视图会显示模型正在写第几个场景；原始回复可通过"查看原始回复"展开。

颜色、间距和字体都定义为 `public/styles.css` 顶部的设计变量（中性锌灰配一种粉色强调色，含浅色和深色两套）。图标是 `public/icons.js` 里的内联 SVG。字体优先使用本机已安装的 Inter，否则使用系统字体。页面不下载任何网络字体，因此离线或无法访问 Google Fonts 时也能正常使用。

## 配置

以下各项均为可选。在应用中保存的设置优先于网关相关的环境变量。

| 变量 | 用途 | 默认值 |
| --- | --- | --- |
| `PORT` | 服务监听的端口 | `3789` |
| `HOST` | 服务绑定的地址 | `127.0.0.1` |
| `DATA_DIR` | 历史记录和媒体文件的存放位置 | `data/` |
| `DATABASE_URL`、`POSTGRES_URL` | Postgres 连接串；设置后所有内容存入数据库 | 无 |
| `ADMIN_EMAIL`、`ADMIN_PASSWORD` | 首次启动时创建管理员 | 无 |
| `ALLOW_SIGNUP` | 设为 `false` 关闭注册 | 开放 |
| `GATEWAY_CONFIG_FILE` | 旧版网关文件，仅在尚未保存任何网关时读取一次 | `data/gateway.json` |
| `LLM_PROVIDER` | 初始网关使用的服务商预设 | 演示模式 |
| `BASE_URL_API`、`LLM_BASE_URL` | 初始网关的接口地址 | 预设值 |
| `API_KEY`、`LLM_API_KEY` | 初始网关的 API 密钥 | 无 |
| `LLM_MODEL` | 初始网关的模型 | 预设值 |
| `IMAGE_BASE_URL_API`、`IMAGE_MODEL`、`IMAGE_API_KEY` | 图片生成的默认设置 | 关闭 |
| `VIDEO_BASE_URL_API`、`VIDEO_MODEL`、`VIDEO_API_KEY` | 视频生成的默认设置 | 关闭 |

## 开发者

Video Scripter 是纯 Node.js 项目，没有依赖，也没有构建步骤。

```bash
npm run dev
```

```bash
npm test
```

`npm run dev` 会在文件变化时重启服务。`npm test` 用 `node --test` 运行测试。

### 项目结构

```
server.mjs              HTTP 服务、API 路由、静态文件
src/gateway/            服务商预设、配置存储、流式客户端、演示服务
src/platforms.mjs       各平台的写作、发布与合规指引
src/frameworks.mjs      脚本结构及各阶段的时长分配
src/styles.mjs          图片和视频的画面风格
src/shots.mjs           同一场景多张图片之间的关系（多图模式）
src/prompt.mjs          需求 -> 时间线和提示词；模型回复 -> 脚本
src/store.mjs           保存的历史记录和生成的媒体文件（data/）
src/package.mjs         单份脚本的 .zip 下载包（由 src/zip.mjs 写出压缩包）
public/                 网页界面
test/                   node --test
```

### 按需定制

| 想改什么 | 修改位置 |
| --- | --- |
| 某个平台的脚本写法 | `src/platforms.mjs` 中该平台的条目，文字会直接进入系统提示词 |
| 脚本结构和阶段时长 | `src/frameworks.mjs` |
| 画面风格 | `src/styles.mjs` |
| 多图模式 | `src/shots.mjs` |
| 服务商预设 | `src/gateway/providers.mjs` |
| 界面翻译 | `public/i18n.js` |

"黄金留存"结构来自 B2B 4K 短视频技能（钩子、悬念锚点、三层价值、结构化收束、无预警收尾）；中文脚本里"英文只出现在屏幕上、不进旁白"的规则也出自同一来源。

### 接口协议

`src/gateway/client.mjs` 实现了两种协议，均为流式：OpenAI 兼容的 `chat/completions` 和 Anthropic 的 `messages`。

| 用途 | 请求 |
| --- | --- |
| 列出模型 | `GET {base}/models`，Anthropic 为 `/v1/models` |
| 生成图片 | `POST {base}/images/generations` |
| 发起视频任务 | `POST {base}/videos` |
| 查询视频任务 | `GET {base}/videos/{id}` |
| 下载视频 | `GET {base}/videos/{id}/content` |

图片和视频生成使用 OpenAI 兼容的媒体接口。

### HTTP API

| 方法 | 路径 | 用途 |
| --- | --- | --- |
| `GET` | `/api/meta` | 平台、脚本结构和服务商预设 |
| `GET` | `/api/gateway/config` | 所有已保存的网关（密钥已打码）和当前使用的网关 |
| `PUT` | `/api/gateway/config` | 新建网关，或更新指定 `id` 的网关；`activate: true` 表示启用它 |
| `POST` | `/api/gateway/select` | `{ id, model? }` 选择用来写脚本的网关及其已启用的某个模型 |
| `POST` | `/api/gateway/delete` | `{ id }` 删除网关 |
| `POST` | `/api/gateway/test` | 测试请求体中的设置，不保存 |
| `POST` | `/api/gateway/models` | 按请求体中的设置列出服务商的模型，不保存；`kind: "image" \| "video"` 改为向对应的地址查询 |
| `GET` | `/api/history` | 所有已保存的脚本，最新的在前 |
| `POST` | `/api/history` | 保存一份脚本 |
| `POST` | `/api/history/package` | `{ id, markdown }` 返回该脚本的 `.zip` |
| `POST` | `/api/media/image` | `{ visual, camera, historyId, sceneId }` 生成并保存一张图片，返回 `{ url }` |
| `POST` | `/api/media/video` | `{ visual, camera, start, end }` 发起一个视频任务 |
| `POST` | `/api/media/video/status` | `{ id, historyId, sceneId }` 查询任务，完成后保存文件 |
| `GET` | `/media/<file>` | 已保存的图片或视频 |
| `POST` | `/api/generate` | 服务器发送事件（SSE）：`plan`、`delta`、`done` 或 `error` |
