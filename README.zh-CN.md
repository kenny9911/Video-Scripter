# Video Scripter 短视频脚本创作工具

为视频号、抖音、TikTok、Instagram Reels、YouTube Shorts 写短视频脚本。每个平台各出一份脚本：分镜时间线、旁白、屏幕文字、画面与镜头、音效，以及标题、封面文字、描述、话题标签和置顶评论。English: [README.md](README.md)

## 启动

需要 Node.js 20 以上，无需安装依赖。

```bash
node server.mjs
```

打开 http://localhost:3789 。右上角的 **中文 / English** 按钮切换界面语言，**☾ 深色 / ☀ 浅色** 按钮切换主题。首次启动是演示模式（只返回占位文字），点击 **模型设置** 连接真实模型。

## 模型网关

- **多个网关**：为每个服务商或账号保存一个网关（服务商、BASE_URL_API、API_KEY、默认模型），可新建、编辑、删除，并勾选"用这个网关写脚本"。
- **列出可用模型**：向服务商查询当前密钥可用的模型，勾选后会出现在需求表单的"写作模型"选择器里。
- **图片和视频**：每个网关可以单独设置图片和视频各自的 BASE_URL_API、模型、尺寸和可选的 API_KEY，也可以列出该地址的可用模型。接口地址或密钥留空时使用网关的设置；模型留空即关闭。
- **密钥安全**：密钥只保存在本机的 `data/gateway.json`（权限 600，已加入 .gitignore），浏览器只能看到打码后的预览。更改服务商或接口地址会清除已保存的密钥。

支持 OpenAI 兼容接口（`/chat/completions`）和 Anthropic 接口（`/v1/messages`）。图片使用 `POST {base}/images/generations`；视频使用 `POST {base}/videos`，再轮询 `GET {base}/videos/{id}` 并下载 `/content`。

## 画面风格

需求表单里的 **画面风格** 提供 27 种风格，分为实拍、插画、三维与定格、图形与数据、年代与氛围五组。可选一种，或选两种混合（先选的为主）。所选风格会告诉写作模型每个场景该怎么写画面，也会写进该脚本所有图片和视频的提示词。风格定义在 `src/styles.mjs`。

## 生成图片和视频

当前网关设置了图片或视频模型后，脚本的每个场景下会出现"生成图片 / 生成视频"按钮。勾选需求表单里的"同时为每个场景生成图片"，脚本写完后会自动为所有场景出图。**每个场景的图片数**（1 到 3，默认 1）决定每次为一个场景生成几张备选图，每张都是一次单独的请求。

## 保存的内容

所有内容都保存在本机的 `data/` 目录，不依赖浏览器：

- `data/history.json`：每一份写完的脚本（需求、计划、脚本），数量不限，在 **历史记录** 中打开。
- `data/media/`：每一张生成的图片和每一段视频，并关联到对应脚本；重新生成不会删除旧文件。

脚本页的 **下载 .zip** 会把该脚本的全部内容打包，文件名为 `<日期>_<平台>_<标题>.zip`（例如 `2026-11-10_douyin_AI-落地的三个坑.zip`），内含 `script.md`、`script.json`、`voiceover.txt`，以及 `images/scene-01_00m00s-00m04s.png`、`videos/scene-01_00m00s-00m04s.mp4` 这样按场景编号和时间码命名的图片与视频。

备份或迁移时复制整个 `data/` 目录即可。可用环境变量 `DATA_DIR` 指定其他位置。

## 测试

```bash
node --test
```
