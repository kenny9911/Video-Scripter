# 视频号双引擎与合规获客

## 双引擎

1. 完播率。短视频（45–90 秒）要过半完播；3–6 分钟的顾问长课靠架构图渐进推演和章节留存。
2. 熟人社交裂变。点赞会把视频推给点赞者的朋友，转发进高管群、研发群、朋友圈才是主要流量。所以内容必须至少具备一种属性：
   - 高管学习教材属性：老板看完会直接转给 CTO 或业务负责人，要求对齐认知。
   - 强利他工具属性：可以抄作业的架构图、避坑清单、落地步骤。

策划时先回答：谁会把这条视频转给谁，转的时候会说哪一句话？答不出来，这个选题就还没想清楚。

## 受众与语气

- 受众是老板、高管、技术负责人。语气稳，有判断，像懂行的顾问在讲；不玩梗，不夸张，不贩卖焦虑。
- 转发指令具体到人和理由：“转给你们负责数字化的那位同事，让他先看第二层”，不要“欢迎转发”。

## 合规防限流

- 口播和字幕里不出现“加微信”“微信号”“转账”，不出现站外平台名和外部链接。
- 引流只用两种说法：
  - “评论区置顶领高清讲义 PDF”（需求里给了讲义名就用原名）。
  - “私信预约企业内训或架构咨询”。
- 不用广告法极限词（最好、第一、唯一、百分之百、国家级），不承诺无法证实的效果和收益。

## 发布素材（生成脚本时）

- 封面标题给 3 组高反差备选，单行不超过 12 个汉字。
- description 是左下角的发布文案：痛点提问 + 三点干货 + 一句点睛 + 定向转发引导。
- shareLine 是朋友圈和高管群的转发导语：站在转发者的立场写一两句，说清为什么值得同事看。
- pinnedComment 是评论区置顶的获客钩子：引导回复关键词领取讲义，或私信预约内训、架构咨询。
- 3 分钟以上的视频给 chapters：带时间戳的章节进度条，每章标题不超过 10 个汉字。
