# 顾问级白板授课

这是一堂 3–6 分钟的公开课，不是一条拉长的短视频。讲的人是企业咨询顾问和内训导师，听的人是会把它收藏、转给团队的老板和技术负责人。

## 一张图讲到底

- 全片围绕一张架构图（板书）展开。策划时先定这张图：分几层或几栏，每块叫什么，块与块之间的箭头是什么。
- 渐进推演：图不是一次摆出来的。讲到哪一块，才画出或点亮哪一块。先搭全局骨架，再放大其中一块讲微观构造，最后回到全局给出结论。
- 观众最后截图保存的就是这张完整的图，所以每一块的名字要短，能直接当讲义用。

## 章节

- 每章 30–60 秒，只讲图上的一块，一章只给一个结论。
- 每章三步：用问题开场（“那这一层到底管什么？”）→ 推演 → 一句话落点。章末抛出下一章要回答的问题。
- 开场先破一个商业神话或给一个反常识的事实，交代为什么值得花几分钟；然后才进入图。

## 口播

- 用指向性的话带着观众看图：“先看最底下这一层”“中间这一块，是今天的重点”“从这里拉一根线到上面”。
- 讲组件时固定句式：它是什么（人话）→ 它叫什么（术语）→ 没有它会怎样。
- 讲课不等于念稿：照样用短句，每 12–15 秒一次转折，隔一段回扣主线问题。
- 至少一处讲自己做咨询或内训时的真实现象，让这堂课有别于教科书。

## 讲义转化

- 结尾把这张图称为“讲义”或“架构图”：引导在评论区置顶领取高清版，或私信预约企业内训、架构咨询。
- 落地部分给三步：先从哪个场景做、谁牵头、做到什么算第一步完成。

## 生成脚本时

- whiteboard 必填：用 ASCII 画出完整板书，左中右三栏或自下而上四层，标出每块的名字和箭头方向。
- 每个场景的 visual 写清讲师动作和板书变化（这一步新画出或点亮了哪一块）。onScreenText 用讲义风的短句。
- 超过 3 分钟给 chapters，时间戳对齐每章的第一个场景。
