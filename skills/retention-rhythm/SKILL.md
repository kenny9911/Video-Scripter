# 完播节拍

完播率是分发的生死线。节拍在策划时就定好，不是写完再补。

## 短视频（45–90 秒）

- 前 3 秒定生死。第一句只做一件事：让目标观众觉得“这说的是我”或“这和我以为的相反”。不铺垫，不定义，不自我介绍。
- 第二拍（5–12 秒）说清看完能得到什么：能避开什么损失、终于弄懂什么、能照着做什么。可以预告“最后一点最要紧”，但预告了就必须兑现。
- 每 12–15 秒（大约 50–65 个字）安排一次转折。转折可以是：一个反问、一个“但是”、一个反差数字、一个具体场景、换一个对象说话（“如果你是老板…”）。连续 18 秒以上平铺直叙，观众就划走了。
- 开头埋的悬念必须在后三分之一兑现，兑现时点明（“这就是开头说的那件事”）。
- 最有价值的一点放在最后一个实质段落，不要放在开头用掉。

## 长课（3–6 分钟）

- 靠“一张图渐进推演 + 可点击的章节”留人：每章 30–60 秒，只讲图上的一块。
- 每章三步：用一个问题开场 → 推演 → 一句话落到结论。章末抛出下一章要回答的问题，把观众带过去。
- 每一分钟回扣一次全片的主线问题，让中途点进来的人也跟得上。

## 结尾

- 无预警收尾：金句 → 具体的转发或领取指令 → 下期要回答的一个问题。不出现任何结束预告词。
- 金句是全片核心认知的再说一遍，不是新观点。
- 结尾控制在全片的 8–12%。说完就停，不寒暄。
